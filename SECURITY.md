# Security

Please don't report security problems in public issues.

Report them privately through GitHub: open the repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it, and the Rex version and OS.

We aim to reply within a few days. Fixes ship in the next release; only the latest release is supported.

Things we especially want to hear about: a bot escaping its workspace sandbox, a bot or web page reading stored logins or keys, bypassing an approval prompt, and access to the loopback API without the per-launch token. The [known limits](README.md#known-limits) in the README are documented behaviour, not vulnerabilities.
